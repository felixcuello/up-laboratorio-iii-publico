# Laboratorio III

## Introducción

Este es el repositorio NO oficial de la materia Laboratorio III.

La idea de este repositorio es que aquí estén subidos todos los recursos de la materia relacionadas con código,
configuración del entorno de desarrollo y demás archivos que puedan resultar útiles para los estudiantes de la materia.

## Directorios

En este repositorio se encuentran los siguientes directorios:

- `entorno/`: Contiene los archivos para el entorno de programación
- `entorno/ejemplos/`: Contiene ejemplos de código para la materia que pueden ser vistos desde el entorno. Si vos querés
  utilizar un editor local y verlo dentro del entorno siempre tenés que crear los archivos adentro del directorio
  `entorno` (te recomendamos crear un subdirectorio aparte para tus archivos para que esté más ordenado).
